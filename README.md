## 1. Что это за проект

Данный проект представляет собой полноценную образовательную веб-страницу, вдохновленную архитектурой пользовательского опыта (UX), дизайном и кинематографической подачей страницы Tesla Model X.

Главная цель проекта — обучить начинающих и практикующих фронтенд-разработчиков созданию современных сайтов премиум-уровня с использованием исключительно стандартов веб-платформы:
- Без тяжелых фреймворков (без React, Vue, Angular);
- Без серверного бэкенда и баз данных;
- Без сторонних зависимостей.

Сайт работает автономно: достаточно открыть файл `index.html` в любом современном браузере.

---

## 2. Используемые технологии

- **HTML5**: Семантическая структура (`<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`), микроразметка OpenGraph, теги доступности ARIA.
- **CSS3**:
  - CSS Custom Properties (дизайн-токены и переменные);
  - CSS Grid и Flexbox для адаптивной верстки;
  - Backdrop Blur (эффект матового стекла);
  - Аппаратные GPU-анимации (`transform`, `opacity`).
- **Vanilla JavaScript (ES6+)**:
  - Модульная архитектура (`import` / `export`);
  - `IntersectionObserver API` для отслеживания видимости;
  - `requestAnimationFrame` для гладких счётчиков и симуляций;
  - Обработка жестов Touch/Swipe и клавиатурных событий (A11y).

## 4. Как устроен HTML

Файл `index.html` построен по принципу чистой семантики:
1. `<header class="site-header">` — фиксированная навигационная панель. Содержит логотип, якорные ссылки и кнопку конфигуратора.
2. `<section class="hero-section">` — полноэкранный первый экран (100vh) с заголовком и кнопками быстрого перехода.
3. `<section class="specs-section">` — панель ключевых характеристик (запас хода, ускорение, вместимость).
4. `<section class="interior-section">` — блок интерьера с трёхмерным переключением рядов и галереей.
5. `<section class="perf-section">` — кинематографичный тёмный блок ускорения и мощности.
6. `<section class="config-section">` — встроенный интерактивный конфигуратор.
7. `<section class="exterior-section">` — интерактивные подъёмные двери Falcon Wing.
8. `<section class="utility-section">` — демонстрация объёма багажного отделения.
9. `<section class="charging-section">` — симулятор процесса ультрабыстрой зарядки.
10. `<section class="tech-section">` и `<section class="safety-section">` — карточки инноваций и систем безопасности.
11. `<div class="modal-overlay">` — диалоговое окно конфигуратора с атрибутами `role="dialog"` и `aria-modal="true"`.
12. `<footer class="site-footer">` — обязательный юридический дисклеймер и структура проекта.

## 5. Как работает CSS

Стили разделены по принципу единственной ответственности:
- `reset.css`: убирает нежелательные отступы браузеров по умолчанию и задаёт `box-sizing: border-box`.
- `variables.css`: объявляет цветовую палитру (чёрный `#000000`, оттенки серого, акцентный синий `#3b82f6`), радиусы скруглений, параметры `backdrop-filter: blur(...)`.
- `main.css`: задаёт блочную структуру, типографику, оформление кнопок и карточек.
- `responsive.css`: плавно адаптирует элементы под разрешения:
  - 1440px+ (Широкие десктопы)
  - 1200px (Стандартные ноутбуки)
  - 1024px (Планшеты, переключение на гамбургер-меню)
  - 768px (Мобильные экраны: вертикальная колонка, крупные области нажатия)
  - 480px и 360px (Компактные смартфоны без горизонтального скролла)
- `animations.css`: содержит ключевые кадры `@keyframes`, аппаратное ускорение и директиву `@media (prefers-reduced-motion: reduce)` для людей с чувствительностью к анимациям.

## 6. Как работает JavaScript

JavaScript использует нативную модульную систему ES6 (`type="module"`):
1. В `index.html` подключается только точка входа:
   ```html
   <script type="module" src="./js/main.js"></script>
   ```
2. Модуль `main.js` импортирует функции из остальных файлов (`navigation.js`, `animations.js` и т.д.) и вызывает их после срабатывания события `DOMContentLoaded`.
3. Состояние хранится в памяти браузера в виде обычных JavaScript-объектов, что обеспечивает мгновенный отклик интерфейса без задержек.

## 7. Как работают анимации

Анимации оптимизированы для частоты кадров 60–120 FPS:
- Анимируются только свойства `transform` и `opacity`, которые обрабатываются графическим процессором (GPU) без перерасчёта геометрии документа (`layout/reflow`).
- Подъём дверей Falcon Wing реализован через CSS-трансформации `transform: translateY(...) rotate(...)` с точкой поворота `transform-origin: top center`.

## 8. Как работает IntersectionObserver

Вместо устаревшего и ресурсоёмкого отслеживания каждого пикселя прокрутки `window.addEventListener('scroll', ...)`, браузер использует встроенный API `IntersectionObserver`:
```javascript
const observer = new IntersectionObserver((entries, obs) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      entry.target.classList.add('is-visible');
      obs.unobserve(entry.target); // Отключаем наблюдение, чтобы анимация не перезапускалась
    }
  });
}, { threshold: 0.15 });
```
Это снижает нагрузку на процессор мобильных устройств практически до нуля.

## 9. Как работает конфигуратор автомобиля

1. В файле `js/configurator.js` хранится объект состояния:
   ```javascript
   export const configState = {
     model: 'Модель X',
     color: 'Перламутровый белый',
     colorKey: 'white',
     wheels: '20″ Sport',
     seats: '5 мест',
   };
   ```
2. При клике на цвет, диск или сиденье вызывается обработчик, обновляющий свойство в объекте `configState`.
3. Функция `updateConfigUI()` синхронно обновляет:
   - CSS-фильтр цвета на изображении автомобиля;
   - Текстовые метки;
   - Сводку комплектации на странице и в модальном окне.

## 10. Как работает галерея и просмотр салона

- **Карусель**: отслеживает текущий индекс `currentIndex`. Кнопки «Вперёд» и «Назад» переключают класс `.active`.
- **Сенсорные экраны**: события `touchstart` и `touchend` замеряют разницу координат `screenX`. Если сдвиг больше 50 пикселей, слайд перелистывается.
- **Клавиатура**: поддерживаются стрелки влево и вправо для доступности (A11y).
- **Интерактивный салон**: 3 кнопки («Передний ряд», «Второй ряд», «Третий ряд») переключают видимость слоёв изображений с мягким полупрозрачным переходом (`crossfade`).

## 11. Как устроено модальное окно

1. Модальное окно скрыто по умолчанию через CSS `display: none`.
2. При нажатии любой кнопки `data-open-modal="configurator"` добавляется класс `.is-active`.
3. Прокрутка основного документа блокируется (`document.body.style.overflow = 'hidden'`), предотвращая случайную прокрутку под окном.
4. Окно закрывается тремя способами:
   - Клик по кнопке-крестику «✕» или кнопке «НАЗАД»;
   - Нажатие клавиши `Escape` на клавиатуре;
   - Клик по полупрозрачной подложке (Backdrop) вокруг окна.
5. При нажатии «ГОТОВО» отображается демонстрационное уведомление об успешном завершении без сбора личной информации.

## 12. Как заменить изображения

Все изображения находятся в папке `assets/images/`:
- `hero.jpg` — главный баннер автомобиля
- `interior-front.jpg` — вид передней части салона
- `interior-second-row.jpg` — второй ряд сидений
- `exterior-falcon.jpg` — автомобиль с открытыми дверями
- `charging.jpg` — ночная станция зарядки

Чтобы заменить любое фото, просто поместите ваш файл с тем же именем в папку `assets/images/`, либо измените пути в файле `js/main.js` в объекте:
```javascript
export const MEDIA = {
  hero: './assets/images/hero.jpg',
  interiorFront: './assets/images/interior-front.jpg',
  // ...
};
```

## 13. Как добавить или заменить фоновое видео

1. Поместите MP4 файл (например, `hero.mp4`) в папку `assets/video/`.
2. В файле `index.html` внутри контейнера `<div class="hero-media-wrapper">` добавьте тег `<video>`:
   ```html
   <video autoplay muted loop playsinline poster="./assets/images/hero.jpg" class="hero-video">
     <source src="./assets/video/hero.mp4" type="video/mp4" />
   </video>
   ```

## 14. Как запустить проект локально

Так как проект написан на чистом HTML, CSS и JavaScript:

### Способ 1: Прямое открытие файла
Просто дважды кликните по файлу `index.html` в проводнике Windows или Finder на macOS.

### Способ 2: С помощью простого локального сервера (рекомендуется для ES-модулей)
Если у вас установлен Python:
```bash
python3 -m http.server 8000
```
И откройте в браузере: `http://localhost:8000`

Если у вас установлен Node.js:
```bash
npx serve .
```

## 15. Как создать репозиторий на GitHub

1. Зайдите на сайт [github.com](https://github.com/) и войдите в свой аккаунт.
2. В правом верхнем углу нажмите кнопку **«+»** и выберите **«New repository»**.
3. В поле **Repository name** укажите имя, например: `model-x-educational-concept`.
4. Оставьте репозиторий **Public** (публичным).
5. Не ставьте галочки «Add a README file» или «Add .gitignore» (они уже есть в проекте).
6. Нажмите зелёную кнопку **«Create repository»**.

## 16. Как загрузить проект в GitHub

Откройте терминал в папке проекта и выполните по порядку следующие команды:

```bash
# 1. Инициализация локального git-репозитория (если ещё не создан)
git init

# 2. Добавление всех файлов проекта
git add .

# 3. Создание первого коммита
git commit -m "Первоначальный релиз образовательного проекта Модель X"

# 4. Переименование главной ветки в main
git branch -M main

# 5. Привязка удаленного репозитория GitHub (замените YOUR_USERNAME и REPO_NAME)
git remote add origin https://github.com/YOUR_USERNAME/model-x-educational-concept.git

# 6. Отправка файлов на GitHub
git push -u origin main
```

## 17. Как включить GitHub Pages

Благодаря настроенному файлу `.github/workflows/deploy.yml`, развёртывание автоматизировано:

1. Перейдите в ваш репозиторий на GitHub.
2. Нажмите вкладку **«Settings»** (Настройки).
3. В левом боковом меню выберите раздел **«Pages»**.
4. В блоке **«Build and deployment»** в выпадающем списке **Source** выберите:
   **«GitHub Actions»**.
5. Подождите 1–2 минуты, пока действие выполнится во вкладке **Actions**.
6. На вкладке Pages появится ссылка на ваш опубликованный сайт, например:  
   `https://YOUR_USERNAME.github.io/model-x-educational-concept/`

## 18. Как вносить изменения после публикации

Когда вы измените текст, стили или изображения на компьютере, отправьте обновления одной цепочкой команд:

```bash
git add .
git commit -m "Обновление стилей и характеристик"
git push
```
GitHub Actions автоматически пересоберёт и опубликует обновленную версию в течение одной минуты.
